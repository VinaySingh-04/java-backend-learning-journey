#  Student Management System

A console-based **Student Management System** developed using **Core Java**. This project was built as part of my Java Backend Developer learning journey to strengthen my understanding of Object-Oriented Programming (OOP), Collections Framework, File Handling, Exception Handling, and professional software development practices.

The application allows users to manage student records through a menu-driven interface. It supports adding, viewing, searching, updating, deleting, and analyzing student data while storing records in a text file for persistence.

---

#  Project Objectives

* Build a real-world Java console application from scratch.

* Learn CRUD (Create, Read, Update, Delete) operations.
